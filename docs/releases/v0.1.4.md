# v0.1.4 release notes — local draft

This is an **unpublished preparation draft**. Source ZIP/TAR, checksums and
scoped host tests passed on fixed integration commit `05768c8`. The delivery
revision is recorded separately in `BUILD_COMMIT.txt` and `SHA256SUMS`; no
release workflow or publication is claimed.

- The core candidate carries the admitted text request/source identity repair,
  workspace-relative tool paths, and bounded source-manifest checks.
- OpenCode V2, Claude Code and Codex have candidate-specific host validation;
  compatibility-wire model runs are functional evidence, not performance
  comparisons. NanoBot 0.4.1 passed scoped macOS AgentLoop and permission tests;
  each persistent turn requires a stock `read_file` selection before direct
  SparseRead source access, and shell operations remain native. One limited
  `deepseek-flash` workflow used the stock NanoBot AgentLoop and Chat SSE
  without a protocol converter; this is functional evidence, not a benchmark.
- The `05768c8` source ZIP was exercised with Pi 0.87.1 and OpenClaw
  2026.7.1-2 on macOS; these fixed-version regressions do not claim a latest
  upgrade. OpenCode 2.3.0 and Codex 0.169.0 source ZIP host checks also passed.
- Candidate validation, exact versions and platform limits are tracked in
  `docs/framework_upgrade_20261114/validation-summary.md`. Existing historical
  `v0.1.3` tags and experimental results remain unchanged.

Windows, Desktop and remote surfaces must not be inferred from macOS CLI tests.
